# Project Timeline

## 1. Project Overview

The Pac-Man project was developed incrementally using Git and GitHub. The team followed a progressive development approach: first establishing the basic game structure, then implementing gameplay mechanics, user interface screens, advanced ghost behavior, configuration validation, cheat mode, and finally code quality improvements.

The repository history provides evidence of continuous development through commits made between August 31 and October 4, 2026.

## 3. Development Approach

The project was developed iteratively rather than implementing all features at once.

Each major feature was implemented, tested, corrected, and committed separately. Examples include:

- `ghost with random movment`
- `just added bfs`
- `ghost movment and main`
- `game over, lives`
- `pause screen`
- `added a cheat mode button and fixed the pause screen`
- `CheatMode`
- `did flake8 and fixed the seed`
- `added a rect class so i can create my own collidepoint`
- `added duc string`

This approach allowed the team to identify problems early and improve existing functionality without waiting until the end of the project.
